# Security

Please report vulnerabilities privately through GitHub's
**Security → Report a vulnerability** on this repository rather than in a
public issue.

In scope:

- Anything that lets posting text from a job board run script on the published
  page, or inject formulas into the CSV.
- Anything that lets a job board's response write outside `data/`, `docs/` and
  `README.md`, or change the workflow's behaviour.
- Leaks of repository secrets through logs or published files.

Out of scope: the content of third-party job postings, and the availability of
the job boards themselves.

This project stores no personal data, has no accounts, and never submits
applications or forms on anyone's behalf.
